# Налоговый калькулятор — модульная сборка

## Структура
- `index.html` — разметка приложения и подключение ресурсов.
- `css/` — стили, разделённые по слоям; `07-fintech-redesign.css` содержит новый визуальный слой.
- `js/` — шесть JavaScript-файлов, перенесённых из исходных блоков в исходном порядке.

## Важно
- Исходные HTML-компоненты и JavaScript-логика перенесены без переписывания.
- Сохранены порядок выполнения скриптов, глобальные функции и inline-обработчики.
- Обновлён только слой оформления: палитра, размеры, карточки, поля, финансовые показатели и адаптивные состояния.
- Ссылки на внешние ресурсы и PWA-манифест оставлены как в исходнике. Если в репозитории есть дополнительные файлы (например, `manifest.json`, изображения или service worker), их нужно сохранить рядом с `index.html` при публикации.
- Для локальной проверки откройте `index.html` через локальный веб-сервер. Некоторые браузерные функции (PWA, камера, хранилища) ограничены при открытии через `file://`.
