# Налоговый калькулятор — Premium Emerald

Статическая веб-версия приложения. Основной файл сайта — `index.html`.

## Публикация через GitHub Pages

1. Создайте новый репозиторий на GitHub.
2. Загрузите в корень репозитория `index.html` и `.nojekyll`.
3. Откройте **Settings → Pages**.
4. В разделе **Build and deployment** выберите **Deploy from a branch**.
5. Выберите ветку `main` и папку `/ (root)`, затем нажмите **Save**.
6. Дождитесь публикации — GitHub покажет адрес сайта в разделе Pages.

## Важно

- Приложение подготовлено как статический сайт; серверная часть для публикации этой HTML-страницы не требуется.
- Для загрузки внешних шрифтов требуется подключение к интернету. При недоступности Google Fonts браузер использует резервные системные шрифты.
- Данные приложения, которые сохраняются браузером, привязаны к браузеру и устройству пользователя. GitHub Pages не синхронизирует их между устройствами.
- Перед публичной публикацией проверьте содержимое приложения и не размещайте в репозитории реальные персональные данные или секретные ключи.
